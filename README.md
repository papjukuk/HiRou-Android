## 🚀 프로젝트 소개
<!-- 여기에 프로젝트가 어떤 앱인지 간단하게 설명해주세요. -->
하이루 (Hi-Rooh)는 [하이루 (Hi-Rooh)는 '물좀마셔줘' 스마트 기기와 연동하여 사용자의 건강한 수분 섭취 습관 형성을 돕는 건강 서비스 애플리케이션입니다.
블루투스 연결을 통해 '물좀마셔줘' 기기에서 측정된 하루 물 섭취량이 실시간으로 앱에 기록됩니다. 이 데이터를 기반으로 사용자는 하루 2L 물 섭취 목표 달성을 위한 진행 상황을 한눈에 확인할 수 있습니다. 목표를 달성하면 축하 알람을 보내 긍정적인 동기를 부여하며, 앱을 통해 주간 통계 등으로 자신의 수분 섭취 패턴을 쉽게 파악하고 관리할 수 있도록 지원합니다.]

### 📝 커밋 메시지 규칙

모든 커밋 메시지는 `[타입]: [설명]` 형태로 작성되어야 합니다.

| 타입      | 설명                               |
| :-------- | :--------------------------------- |
| `feat`    | 새로운 기능 추가                   |
| `fix`     | 버그 수정                          |
| `docs`    | 문서 수정 (코드 변경 없음)         |
| `style`   | 코드 포맷팅, 세미콜론 누락 등 (코드 변경 없음) |
| `refactor`| 코드 리팩토링 (기능 변경 없음)     |
| `test`    | 테스트 코드 작성 또는 리팩토링    |
| `chore`   | 빌드 업무 수정, 패키지 매니저 수정 등 |

<br/>
