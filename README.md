## 🚀 프로젝트 소개
하이루 (Hi-Rooh)는 **스마트 기기**와 연동하여 사용자의 건강한 수분 섭취 습관 형성을 돕는 건강 서비스 애플리케이션입니다.

**블루투스 연결**을 통해 '물좀마셔줘' 기기에서 측정된 하루 물 섭취량이 실시간으로 앱에 기록됩니다. 
이 데이터를 기반으로 사용자는 **하루 2L 물 섭취 목표 달성**을 위한 진행 상황을 한눈에 확인할 수 있습니다. 
목표를 달성하면 **축하 알람**을 보내 긍정적인 동기를 부여하며, 
앱을 통해 **주간 통계** 등으로 자신의 수분 섭취 패턴을 쉽게 파악하고 관리할 수 있도록 지원합니다.

## ✨ 주요 기능
*   **스마트 기기 연동:** '물좀마셔줘' 기기와의 Bluetooth Low Energy (BLE) 연결을 통한 실시간 물 섭취량 측정
*   **사용자 설정 관리:** 개인화된 알림 시간 및 목표 설정 등 앱 사용 환경 맞춤 설정 기능
*   **통계 및 패턴 분석:** 주간 물 섭취량 통계 제공 및 섭취 패턴 분석
*   **목표 달성 알림:** 하루 물 섭취 목표 달성 시 축하 알람 제공
*   **알람 스케줄링:** 정해진 시간에 정확히 알림을 받을 수 있는 알람 스케줄링 기능

## 🤝 기여 가이드라인

### 📝 커밋 메시지 규칙

모든 커밋 메시지는 `[타입]: [설명]` 형태로 작성되어야 합니다.

| 타입      | 설명                               |
| :-------- | :--------------------------------- |
| `feat`    | 새로운 기능 추가                   |
| `fix`     | 버그 수정                          |
| `docs`    | 문서 수정 (코드 변경 없음)         |
| `style`   | 코드 포맷팅, 세미콜론 누락 등 (코드 변경 없음) |
| `refactor`| 코드 리팩토링 (기능 변경 없음)     |
| `test`    | 테스트 코드 작성 또는 리팩토링    |
| `chore`   | 빌드 업무 수정, 패키지 매니저 수정 등 |
